Mikrofon im Browser freigeben

Browser sperren das Mikrofon auf lokalen HTTP-Adressen. So schaltest du das Megafon frei:

  1. Neuen Tab öffnen, in Chrome mit chrome:// statt brave://
  2. Diese Adresse eintragen
  3. Auswahl auf Enabled stellen
  4. Relaunch klicken

In Brave zusätzlich über das Löwen-Symbol das Mikrofon erlauben.
